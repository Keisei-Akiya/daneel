# 0003: UI フレームワークに React ではなく SolidJS を使う

Status: Accepted (2026-11-23)

## 決定

UI は SolidJS で作る。

## 理由

1. React は仮想 DOM のせいで、さまざまな問題がある。
   - 再レンダリングを抑制しなければならない。
   - オーバーヘッドがかかる。
   - useMemo などを書きまくる必要がある。
   - AI にそれを正しく書かせるよう統制するのが面倒。

   だから、仮想 DOM を使わないものを使いたかった。
2. 候補は Svelte と SolidJS だった。
3. 状態を直接変更せず、状態を触る関数を操作して変更する、という React の考え方が好きだった。
   SolidJS はその点を継承している。
